# Demenagement

## Team Setup — Claude Code

After cloning, run these steps once to activate AI-assisted development.

### 1. Install the Superpowers plugin

```bash
/plugin install superpowers@claude-plugins-official
```

### 2. Activate skills

```bash
npx skills install
```

This generates the `.claude/skills/` symlinks on your machine from the skills already in the repo.

### 3. Add the Context7 MCP (up-to-date docs in Claude)

```bash
claude mcp add --scope user context7 -- npx -y @upstash/context7-mcp
```

## Skills included

| Skill | Purpose |
|---|---|
| `frontend-design` | UI/UX component design guidance |
| `remotion-best-practices` | Remotion video development patterns |
| `composio` | API integrations and tool connections |
| `skill-creator` | Create new custom skills |

Skills are applied **automatically** by Claude before every development task. No manual invocation needed.

---

## How it works

- `.agents/skills/` — skill files committed to this repo
- `.claude/settings.json` — project-level Claude Code config (superpowers enabled)
- `skills-lock.json` — skills version lockfile
- `.claude/skills/` — machine-local symlinks (gitignored, regenerated by `npx skills install`)
- `.claude/settings.local.json` — personal overrides (gitignored)
